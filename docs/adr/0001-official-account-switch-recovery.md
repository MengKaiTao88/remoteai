# 官方账号切换时在原会话恢复

官方账号切换后的续聊沿用原 Codex 会话 ID、消息时间线、工作目录、模型、推理强度和权限设置。代理按现有切号规则选择能使用原模型和推理强度的官方备用账号，由备用账号建立独立的上游连接。

## 恢复规则

- 上游明确因额度拒绝本次生成，且请求符合现有安全重放条件时，代理在原会话自动重试该次生成。已配对的工具调用及结果按原顺序保留。已向客户端提交输出或送达结果不明时，沿用现有的停止条件。
- 备用账号收到当前请求中可完整重放的上下文。代理仅在出站请求副本中处理旧账号的连接状态和可安全省略的账号专属数据，原历史仍由 Codex 保存。后续完整请求、重连和 HTTP 回退也按状态的实际账号归属处理。
- 项目文件继续从原工作目录按现有权限读取。带完整内容的图片和文件沿用现有附件处理。遇到只有原账号能访问的引用，且当前请求缺少独立重放所需的原件或状态时，在原会话结束当次请求并保留已有进度。

## 验收

- 用模拟上游验证原账号耗尽后，备用账号在同一个会话中收到完整可重放的请求，原消息、附件和已完成的工具结果均可继续使用。
- 验证下一轮的历史同时含两个账号的状态时，代理在完整转发和重连中仍按归属处理。
- 验证缺少必需资料、已出流和送达不明的请求都沿用现有重放保护。
