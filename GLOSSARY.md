# Remote AI

Remote AI connects Codex conversations to official accounts and configured providers.

## Language

### Conversation timeline

The ordered messages, progress updates, tool activities, and outcomes visible in a Codex conversation.

### Conversation handoff

Continuing an existing official Codex conversation from Remote AI Web with its original thread ID and conversation owner.

### Default Codex instance

The official Codex Desktop instance that uses the Windows user's default Codex profile.

### Official account model catalog

The models and capabilities available to the active official Codex account. A model's visibility determines whether it appears in that account's picker.

### Official model context override

A user-configured token capacity for an official model. The setting can be saved independently of that model's visibility in the active account's catalog.
